# CEF v0.1 Codec Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Checkpoint Event Format (`docs/protocol/checkpoint-event-format.md`) as a self-contained module in RaceTracker Pro — APRS text and JSON profiles, plus the mapping onto RaceTracker's own status model — with a committed test-vector file other implementers can check their parsers against.

**Architecture:** A pure functional module at `src/services/cef/` with no database, store, or React dependencies. The record defined in spec §4 is the in-memory shape and also the JSON profile, so no separate serialisation layer is needed. APRS text encoding and RaceTracker status mapping are separate files because they change for different reasons: the first tracks the spec, the second tracks our schema. Nothing in this plan touches IndexedDB or the UI.

**Tech Stack:** Plain ES modules, Vitest (globals enabled), no new dependencies. Base64 and byte handling use platform `btoa`/`atob`/`DataView`.

## Global Constraints

- **Spec is authoritative.** `docs/protocol/checkpoint-event-format.md` at commit `fbfcecc`. Where this plan and the spec disagree, the spec wins — stop and flag it.
- **No new npm dependencies.** Everything needed is native.
- **No CBOR.** Spec §6.3 is deliberately out of scope; no implementation exists on either side of the integration yet.
- **No database, store, or UI changes.** Every function in this plan is pure. Wiring is a later plan.
- **No linter or formatter exists in this repo.** Match surrounding style by eye: 2-space indent, single quotes, semicolons.
- **Times are ISO 8601 strings with explicit offset** at every module boundary, matching the repo's existing convention (`src/services/timeUtils.js`). Epoch integers exist only inside the APRS time codec.
- **Test files live in `test/services/cef/`** and import from `../../../src/services/cef/...`.
- **Vitest has `globals: true`** but existing tests import `{ describe, it, expect }` from `vitest` explicitly. Do the same.
- **Coverage target >85%** for new code, per CLAUDE.md.
- **Commit after every task.** Conventional commit prefixes (`feat:`, `test:`, `docs:`).

```javascript
/**
 * Checkpoint Event Format (CEF) v0.1 — record model and JSON profile.
 * Spec: docs/protocol/checkpoint-event-format.md §4, §5.3, §6.2
 */

export const EVENT_TYPES = Object.freeze({
  SEEN: 'SEEN',
  WITHDRAWN: 'WITHDRAWN',
  VET_OUT: 'VET_OUT',
  DNF: 'DNF',
  NON_STARTER: 'NON_STARTER',
});

export const STOP_EVENTS = Object.freeze([
  EVENT_TYPES.WITHDRAWN,
  EVENT_TYPES.VET_OUT,
  EVENT_TYPES.DNF,
  EVENT_TYPES.NON_STARTER,
]);

const COMPETITOR_RE = /^[0-9A-Za-z]+$/;
const REASON_RE = /^[A-Z][A-Z0-9_]*$/;

// Field order for the JSON profile — spec §6.2 lists them in this order.
const FIELDS = ['site', 'competitor', 'event', 'time', 'reason', 'source', 'relays', 'msgId'];

function isPositiveInt(value) {
  return Number.isInteger(value) && value >= 0;
}

/**
 * Validate a record against spec §4.1. Collects every problem rather than
 * failing on the first, so an operator sees one complete report.
 * @param {object} record
 * @returns {{ valid: boolean, errors: string[] }}
 */
export function validateRecord(record) {
  const errors = [];

  if (!record || typeof record !== 'object') {
    return { valid: false, errors: ['record must be an object'] };
  }

  // site — exactly one of checkpoint or location
  const site = record.site;
  if (!site || typeof site !== 'object') {
    errors.push('site is required');
  } else {
    const hasCp = site.checkpoint !== undefined;
    const hasLoc = site.location !== undefined;
    if (hasCp === hasLoc) {
      errors.push('site must have exactly one of checkpoint or location');
    } else if (hasCp && !isPositiveInt(site.checkpoint)) {
      errors.push('site.checkpoint must be a non-negative integer');
    } else if (hasLoc && !isPositiveInt(site.location)) {
      errors.push('site.location must be a non-negative integer');
    }
  }

  if (typeof record.competitor !== 'string' || !COMPETITOR_RE.test(record.competitor)) {
    errors.push('competitor must be a non-empty alphanumeric string');
  }

  if (!Object.values(EVENT_TYPES).includes(record.event)) {
    errors.push(`event must be one of ${Object.values(EVENT_TYPES).join(', ')}`);
  }

  if (typeof record.time !== 'string' || Number.isNaN(Date.parse(record.time))) {
    errors.push('time must be an ISO 8601 string');
  }

  if (record.reason !== undefined) {
    if (record.event === EVENT_TYPES.SEEN) {
      errors.push('reason is only valid on a stop event');
    } else if (typeof record.reason !== 'string' || !REASON_RE.test(record.reason)) {
      errors.push('reason must be an uppercase token');
    }
  }

  if (record.relays !== undefined && !Array.isArray(record.relays)) {
    errors.push('relays must be an array');
  }

  return { valid: errors.length === 0, errors };
}

/**
 * The deduplication identity from spec §5.3: (resolved checkpoint, competitor,
 * event type). A location reference has no identity until resolved — see
 * mapping.resolveSite.
 * @param {object} record
 * @returns {string}
 */
export function naturalKey(record) {
  if (record?.site?.checkpoint === undefined) {
    throw new Error('naturalKey requires a resolved checkpoint; resolve the location reference first');
  }
  return `${record.site.checkpoint}|${record.competitor}|${record.event}`;
}

/**
 * Deduplicate by natural key. Earliest time wins — spec §5.3. This is
 * deliberately the opposite of the last-write-wins rule used when syncing two
 * copies of one device's database: here we are reconciling independent
 * observations of one physical event, and a relay can only add latency.
 * @param {object[]} records
 * @returns {object[]} deduplicated, in first-seen input order
 */
export function mergeRecords(records) {
  const byKey = new Map();
  for (const record of records) {
    const key = naturalKey(record);
    const existing = byKey.get(key);
    if (!existing || Date.parse(record.time) < Date.parse(existing.time)) {
      byKey.set(key, record);
    }
  }
  return [...byKey.values()];
}

function normalise(record) {
  const out = {};
  for (const field of FIELDS) {
    if (record[field] !== undefined) out[field] = record[field];
  }
  return out;
}

/**
 * Encode to the JSON profile (spec §6.2).
 * @param {object|object[]} recordOrRecords
 * @returns {string}
 */
export function encodeJson(recordOrRecords) {
  const records = Array.isArray(recordOrRecords) ? recordOrRecords : [recordOrRecords];
  const payload = records.map(normalise);
  return JSON.stringify(Array.isArray(recordOrRecords) ? payload : payload[0], null, 2);
}

/**
 * Decode the JSON profile. Validates every record; throws on the first invalid
 * one with its full error list.
 * @param {string} jsonString
 * @returns {object[]}
 */
export function decodeJson(jsonString) {
  const parsed = JSON.parse(jsonString);
  const records = Array.isArray(parsed) ? parsed : [parsed];
  return records.map(record => {
    const { valid, errors } = validateRecord(record);
    if (!valid) throw new Error(`Invalid CEF record: ${errors.join('; ')}`);
    return normalise(record);
  });
}
```

```javascript
/**
 * Checkpoint Event Format (CEF) v0.1 — APRS text profile.
 * Spec: docs/protocol/checkpoint-event-format.md §6.1
 */

export const APRS_MAX_LENGTH = 67;

const MAX_EPOCH = 0xFFFFFFFF;

/**
 * Military time zone letters (spec §6.1.1). J means "local time at the sending
 * station" and has no fixed offset. Note the deliberate absence of J from the
 * numeric sequence — I is +9 and K is +10.
 */
const ZONE_OFFSETS = {
  Z: 0,
  A: 1, B: 2, C: 3, D: 4, E: 5, F: 6, G: 7, H: 8, I: 9,
  K: 10, L: 11, M: 12,
  N: -1, O: -2, P: -3, Q: -4, R: -5, S: -6, T: -7, U: -8, V: -9,
  W: -10, X: -11, Y: -12,
};

const EPOCH_TOKEN_RE = /^@([0-9a-zA-Z+/]{6})$/;
const CLOCK_TOKEN_RE = /^(\d\d)\.?(\d\d)(?:\.?(\d\d))?([A-Z])$/;

const TWELVE_HOURS_MS = 12 * 3600 * 1000;

/**
 * Encode an instant as the canonical `@` form: a big-endian uint32 Unix
 * timestamp, base64 with padding stripped. Six characters, 1-second precision,
 * valid until 2106.
 * @param {string} isoString
 * @returns {string} e.g. '@am0qWA'
 */
export function encodeTime(isoString) {
  const ms = Date.parse(isoString);
  if (Number.isNaN(ms)) throw new Error(`Unparseable time: ${isoString}`);

  const epoch = Math.floor(ms / 1000);
  if (epoch < 0 || epoch > MAX_EPOCH) {
    throw new Error(`Time out of range for a uint32 epoch: ${isoString}`);
  }

  const bytes = new Uint8Array(4);
  new DataView(bytes.buffer).setUint32(0, epoch, false); // big-endian
  let binary = '';
  for (const byte of bytes) binary += String.fromCharCode(byte);
  return '@' + btoa(binary).replace(/=+$/, '');
}

function decodeEpochToken(chars) {
  const binary = atob(chars + '==');
  const bytes = new Uint8Array(4);
  for (let i = 0; i < 4; i++) bytes[i] = binary.charCodeAt(i);
  const epoch = new DataView(bytes.buffer).getUint32(0, false);
  return new Date(epoch * 1000).toISOString();
}

/**
 * Resolve a dateless clock time against the receipt instant (spec §6.1.1):
 * the most recent matching instant that is not in the future, rejected if it
 * lands more than 12 hours back.
 */
function decodeClockToken(hh, mm, ss, zone, receivedAt) {
  const hours = Number(hh);
  const minutes = Number(mm);
  const seconds = ss === undefined ? 0 : Number(ss);
  if (hours > 23 || minutes > 59 || seconds > 59) {
    throw new Error(`Invalid clock time: ${hh}${mm}${ss ?? ''}${zone}`);
  }

  const received = Date.parse(receivedAt);
  if (Number.isNaN(received)) throw new Error(`Unparseable receivedAt: ${receivedAt}`);

  let offsetMinutes;
  if (zone === 'J') {
    // Local time at this station. getTimezoneOffset is minutes *behind* UTC.
    offsetMinutes = -new Date(received).getTimezoneOffset();
  } else if (zone in ZONE_OFFSETS) {
    offsetMinutes = ZONE_OFFSETS[zone] * 60;
  } else {
    throw new Error(`Unknown time zone letter: ${zone}`);
  }

  const recv = new Date(received);
  let candidate = Date.UTC(
    recv.getUTCFullYear(), recv.getUTCMonth(), recv.getUTCDate(),
    hours, minutes, seconds,
  ) - offsetMinutes * 60000;

  // Walk back a day if the same-day reading would be in the future.
  if (candidate > received) candidate -= 24 * 3600 * 1000;

  if (received - candidate > TWELVE_HOURS_MS) {
    throw new Error(
      `Clock time ${hh}${mm}${zone} resolves to more than 12 hours before receipt; ` +
      'retransmit using the @ epoch form'
    );
  }

  return new Date(candidate).toISOString();
}

/**
 * Decode any spec §6.1.1 time token to an ISO 8601 UTC instant.
 * @param {string} token e.g. '@am0qWA', '2306Z', '230642Z', '23.06.42Z'
 * @param {string} receivedAt ISO instant of receipt, used only for clock forms
 * @returns {string}
 */
export function decodeTime(token, receivedAt) {
  const epochMatch = EPOCH_TOKEN_RE.exec(token);
  if (epochMatch) return decodeEpochToken(epochMatch[1]);

  const clockMatch = CLOCK_TOKEN_RE.exec(token);
  if (clockMatch) {
    const [, hh, mm, ss, zone] = clockMatch;
    return decodeClockToken(hh, mm, ss, zone, receivedAt);
  }

  throw new Error(`Unrecognised time token: ${token}`);
}
```

```javascript
import { EVENT_TYPES, validateRecord } from './record';

/**
 * Verb letters (spec §6.1.2). N keeps its meaning and position from the 2020
 * Brisbane WICEN format, so a SEEN transmission is byte-identical to existing
 * practice. A parser that does not know a verb must discard the line rather
 * than fall back to SEEN.
 */
export const VERBS = Object.freeze({
  N: EVENT_TYPES.SEEN,
  W: EVENT_TYPES.WITHDRAWN,
  V: EVENT_TYPES.VET_OUT,
  F: EVENT_TYPES.DNF,
  S: EVENT_TYPES.NON_STARTER,
});

const VERB_FOR_EVENT = Object.freeze(
  Object.fromEntries(Object.entries(VERBS).map(([verb, event]) => [event, verb]))
);

/** Reference grammar, spec §6.1.4. */
export const APRS_LINE_RE =
  /^(CP|LC) ?(\d+)T(\d\d\.?\d\d(?:\.?\d\d)?[A-Z]|@[0-9a-zA-Z+/]{6})([NWVFS])([ \w]+)$/;

function sitePrefix(site) {
  return site.checkpoint !== undefined
    ? { prefix: 'CP', number: site.checkpoint }
    : { prefix: 'LC', number: site.location };
}

function groupKey(record) {
  const { prefix, number } = sitePrefix(record.site);
  return `${prefix}${number}|${record.event}|${record.time}`;
}

/**
 * Encode records as APRS text lines (spec §6.1).
 *
 * Returns an array because a large SEEN batch cannot fit the 67-character
 * limit and must be split across transmissions. Records are grouped by site,
 * event and time; stop events emit one line each because they may carry a
 * reason code.
 *
 * @param {object|object[]} recordOrRecords
 * @returns {string[]}
 */
export function encodeAprs(recordOrRecords) {
  const records = Array.isArray(recordOrRecords) ? recordOrRecords : [recordOrRecords];

  for (const record of records) {
    const { valid, errors } = validateRecord(record);
    if (!valid) throw new Error(`Cannot encode invalid CEF record: ${errors.join('; ')}`);
  }

  const groups = new Map();
  for (const record of records) {
    const key = groupKey(record);
    if (!groups.has(key)) groups.set(key, []);
    groups.get(key).push(record);
  }

  const lines = [];
  for (const group of groups.values()) {
    const [first] = group;
    const { prefix, number } = sitePrefix(first.site);
    const header = `${prefix}${number}T${encodeTime(first.time)}${VERB_FOR_EVENT[first.event]}`;

    if (first.event !== EVENT_TYPES.SEEN) {
      // One line per stop event — a reason code applies to a single competitor.
      for (const record of group) {
        const items = record.reason
          ? `${record.competitor} ${record.reason}`
          : record.competitor;
        const line = header + items;
        if (line.length > APRS_MAX_LENGTH) {
          throw new Error(`Encoded line exceeds ${APRS_MAX_LENGTH} characters: ${line}`);
        }
        lines.push(line);
      }
      continue;
    }

    // SEEN: pack as many competitors per line as the limit allows.
    let current = header;
    let count = 0;
    for (const record of group) {
      const addition = count === 0 ? record.competitor : ` ${record.competitor}`;
      if (current.length + addition.length > APRS_MAX_LENGTH) {
        if (count === 0) {
          throw new Error(`Competitor ${record.competitor} does not fit a single line`);
        }
        lines.push(current);
        current = header + record.competitor;
        count = 1;
      } else {
        current += addition;
        count++;
      }
    }
    if (count > 0) lines.push(current);
  }

  return lines;
}

/**
 * Decode an APRS text line into one record per competitor (spec §6.1).
 * @param {string} line
 * @param {string} receivedAt ISO instant of receipt, for dateless time forms
 * @returns {object[]}
 */
export function decodeAprs(line, receivedAt) {
  if (line.length > APRS_MAX_LENGTH) {
    throw new Error(`Line exceeds the ${APRS_MAX_LENGTH}-character limit: ${line.length}`);
  }
  if (/[{}]/.test(line)) {
    throw new Error('Line contains characters forbidden on APRS: { or }');
  }

  const match = APRS_LINE_RE.exec(line);
  if (!match) throw new Error(`Line does not match the CEF APRS grammar: ${line}`);

  const [, prefix, number, timeToken, verb, itemsRaw] = match;
  const event = VERBS[verb];
  if (!event) throw new Error(`Unknown verb: ${verb}`);

  const site = prefix === 'CP'
    ? { checkpoint: Number(number) }
    : { location: Number(number) };
  const time = decodeTime(timeToken, receivedAt);

  const items = itemsRaw.trim().split(/\s+/).filter(Boolean);
  if (items.length === 0) throw new Error(`Line carries no competitors: ${line}`);

  if (event === EVENT_TYPES.SEEN) {
    return items.map(competitor => ({ site, competitor, event, time }));
  }

  // Stop event: one competitor, optional reason code.
  if (items.length > 2) {
    throw new Error(`A stop event carries one competitor and an optional reason: ${line}`);
  }
  const [competitor, reason] = items;
  const record = { site, competitor, event, time };
  if (reason !== undefined) record.reason = reason;
  return [record];
}
```

```javascript
/**
 * Checkpoint Event Format (CEF) v0.1 — mapping onto RaceTracker's own model.
 * Spec: docs/protocol/checkpoint-event-format.md §4.2, §5.1
 *
 * This file tracks *our* schema, not the spec. Keep spec-driven logic in
 * record.js and aprsText.js.
 */

import { RUNNER_STATUSES } from '../../types/index';
import { EVENT_TYPES } from './record';

/**
 * RUNNER_STATUSES has no 'withdrawn' or 'vet-out' value — those are recorded in
 * the withdrawal_records and vet_out_records tables. Both therefore map to the
 * same status and are distinguished by the side effect a caller must also apply.
 */
const EVENT_TO_STATUS = Object.freeze({
  [EVENT_TYPES.SEEN]: { status: RUNNER_STATUSES.PASSED, sideEffect: null },
  [EVENT_TYPES.DNF]: { status: RUNNER_STATUSES.DNF, sideEffect: null },
  [EVENT_TYPES.NON_STARTER]: { status: RUNNER_STATUSES.NON_STARTER, sideEffect: null },
  [EVENT_TYPES.WITHDRAWN]: { status: RUNNER_STATUSES.DNF, sideEffect: 'withdrawal' },
  [EVENT_TYPES.VET_OUT]: { status: RUNNER_STATUSES.DNF, sideEffect: 'vetOut' },
});

/**
 * @param {string} event a CEF event type
 * @returns {{ status: string, sideEffect: 'withdrawal'|'vetOut'|null }}
 */
export function eventToStatus(event) {
  const mapped = EVENT_TO_STATUS[event];
  if (!mapped) throw new Error(`Unknown CEF event type: ${event}`);
  return { ...mapped };
}

/**
 * Inverse mapping, for transmitting our own records.
 *
 * Returns null for statuses that are not protocol events: local device
 * bookkeeping (not-started, called-in, marked-off, pending) describes an
 * operator's workflow rather than anything a competitor did, and
 * disqualification is excluded from CEF v0.1 as an organiser's ruling.
 *
 * Note the asymmetry: 'dnf' maps to DNF, so a caller that needs WITHDRAWN or
 * VET_OUT must check withdrawal_records and vet_out_records first.
 *
 * @param {string} status a RUNNER_STATUSES value
 * @returns {string|null} a CEF event type, or null if not transmissible
 */
export function statusToEvent(status) {
  switch (status) {
    case RUNNER_STATUSES.PASSED: return EVENT_TYPES.SEEN;
    case RUNNER_STATUSES.DNF: return EVENT_TYPES.DNF;
    case RUNNER_STATUSES.NON_STARTER: return EVENT_TYPES.NON_STARTER;
    default: return null;
  }
}

/**
 * Resolve a location reference to a concrete checkpoint (spec §5.1): the
 * earliest checkpoint hosted at that location which the competitor has not been
 * recorded at and which is not earlier than their last recorded checkpoint.
 *
 * A receiver that cannot resolve must reject the record rather than guess, so
 * every failure here throws.
 *
 * @param {{checkpoint?: number, location?: number}} site
 * @param {{ locationCheckpoints?: number[], seenCheckpoints?: number[] }} context
 * @returns {{ checkpoint: number }}
 */
export function resolveSite(site, { locationCheckpoints, seenCheckpoints = [] } = {}) {
  if (site?.checkpoint !== undefined) return { checkpoint: site.checkpoint };

  if (site?.location === undefined) {
    throw new Error('site must have a checkpoint or a location');
  }
  if (!Array.isArray(locationCheckpoints) || locationCheckpoints.length === 0) {
    throw new Error(`No checkpoints known for location ${site.location}; cannot resolve`);
  }

  const seen = new Set(seenCheckpoints);
  const lastSeen = seenCheckpoints.length ? Math.max(...seenCheckpoints) : -Infinity;

  const candidate = [...locationCheckpoints]
    .sort((a, b) => a - b)
    .find(cp => !seen.has(cp) && cp >= lastSeen);

  if (candidate === undefined) {
    throw new Error(
      `No unrecorded checkpoint at location ${site.location} at or after checkpoint ${lastSeen}`
    );
  }
  return { checkpoint: candidate };
}
```

## Out of scope

Named explicitly so nobody fills these in speculatively:

- **UI.** No component emits or ingests a CEF line yet. Deliberate: the format is a draft and the WICEN list has not commented. Add when the format settles.
- **Database wiring.** `eventToStatus` returns a side-effect name; nothing writes `withdrawal_records` or `vet_out_records`. That needs the `CheckpointRepository` / `BaseOperationsRepository` path and belongs in its own plan.
- **HTTP PUT to Stuart's `/api/v3/operatorlog`.** Blocked on a server instance to develop against, and on the `DivisionID` round-trip question.
- **CBOR profile** (spec §6.3) and **transport adaptations** (spec §7). The QR adaptation already exists as `TransferService`; reconciling it with CEF is a later refactor.
- **Playwright journey spec.** CLAUDE.md requires one for every new *feature*; this plan adds no user-visible feature. The journey spec belongs with the UI work.
